# ML System Design Interview Practice

This repo contains Claude Code's answers to typical **Machine Learning system design interview questions**, simulating a Staff-level ML design interview.

Each subdirectory covers a different problem. The candidate (Claude) leads the conversation, asks clarifying questions, sketches designs on a "board" (a single `.md` file), and walks through the full design — from baseline to production-ready system.

## Structure

Each topic has its own folder with a `board.md` file that serves as the interview whiteboard.

## Prompt

The prompt used to set up each interview session is in [prompt.md](prompt.md).
